# smallwave · 네 가지 빨강

현재 둥근 배와 수면 접촉을 유지하고 선체의 페인트 색만 비교한 자료다. `index.html`에서 실제 앱 전체 화면을 402 × 874pt로 보여준다. 색을 하나씩 바꾸거나 4색을 나란히 볼 수 있고, 선택 전 앱의 빨강도 기준으로 확인할 수 있다.

**최종 선택: Tomato red `#D44C38` (2026-09-13).** 사용자의 선택에 따라 앱의 기존 빨강(`MiniatureStyle.drift`, raw ID 2)에 같은 페인트 값을 적용하고 메뉴 이름을 ‘토마토 레드’로 바꿨다. 저장된 색 선택과 신규 설치 기본값은 유지한다. 아래 이미지와 검증 기록은 색을 고를 때 사용한 비교 자료다.

| 색 | 셰이더 페인트 입력 | 전체 화면에서의 인상 |
|---|---|---|
| Tomato red | `#D44C38` | 가장 또렷하고 발랄하다. 작은 배가 쉽게 눈에 들어오며 네 안 중 채도가 가장 강하다. |
| Muted coral red | `#CD6258` | 부드럽고 따뜻하다. 충분한 빨간 존재감과 차분함이 균형을 이룬다. |
| Slightly sun-faded red | `#D3755E` | 밝고 여린 주황·복숭아빛이다. 가장 부드러운 인상을 원할 때 적합하지만 색의 존재감은 약하다. |
| Soft brick red | `#B95243` | 차분하고 안정적이다. 토마토·코랄보다 조금 더 묵직하고 흙빛으로 보인다. |

코드의 색 값은 빛과 물을 거치기 전 페인트 입력이다. 작은 원형 색상표보다 실제 앱의 배를 기준으로 판단한다.

## 고정한 것

- 기준 커밋 `665277eb972751295efb06399073249fa2b6210b`의 배 실루엣·크기·돛·나무·남색 구명환·원본 PNG
- 기존 수면 접촉·굴절 표현과 물리·파동·기울임·부력·관성
- 실제 SwiftUI 화면의 레이아웃·글자·브랜딩·하단 컨트롤
- 공유 앱의 기본색과 기존 3색 선택 메뉴

네 색은 별도 시뮬레이터 검토 앱에서 확인했다. 이 비교 자료를 만들면서 사용자 아이폰에 설치된 앱이나 프로젝트의 앱 소스를 바꾸지 않았다.

## 검증과 이미지

- `native-*.png`: iPhone 17 Pro 시뮬레이터의 실제 앱 캡처. 1206 × 2622px를 402 × 874pt로 표시한다. 배를 한 번 멈춘 뒤 색만 바꾸며 캡처했다. 상태 표시줄 시계는 캡처 시점에 따라 다르다.
- `{color}-{pose}.png`: 동일한 5자세에서 출력한 앱 Metal 장면. 804 × 1748px. 비교색 4개·현재색·procedural reference 각각의 렌더가 물리 상태를 바꾸지 않는지 총 30회 확인했다.
- 현재색은 승인된 빨강과 rest/tilt에서 완전히 같고 shake/flat은 최대 1/255 차이다. inverted에서는 윤곽 29px에 2/255를 넘는 차이(최대 47/255)가 있다. 원인은 분리하지 않았으며 전체 폰 크기에서는 시각적 문제로 확인되지 않았다. procedural reference PNG는 5자세 모두 바이트 단위로 동일하고 물리 상태도 같다.
- `verification.json`: 소스 차이, 같은 물리 상태, 네이티브 화면의 변화 범위.
- `render-verification.json`: 자세별 물리 상태와 렌더 중력 값.
- 네이티브 시뮬레이터 빌드·실행·색 선택·정지 캡처를 확인했다. 실물 iPhone 설치나 센서 검증을 수행한 자료는 아니다.

## 재현

저장소 루트에서 아래 명령은 승인된 기준 커밋으로 새 임시 소스 폴더를 만들고, 검토용 색 매핑과 별도 bundle ID만 적용한다. 공유 앱 소스는 수정하지 않는다.

```sh
python3 References/miniature-art-direction/red-colorways/prepare-preview.py --output /private/tmp/smallwave-red-preview-new
cd /private/tmp/smallwave-red-preview-new
sh scripts/review-miniatures.sh --stills-only --output /private/tmp/smallwave-red-preview-renders
```

기존 임시 폴더가 있으면 다른 빈 경로를 사용한다. `palette.json`이 네 색의 단일 원본이다. 생성된 검토 앱의 색상 ID는 탐색용이며, 실제 앱의 저장된 선택값을 옮기는 변경이 아니다.
