# 장난감 재질 기준 장면

2026-09-10. Mac의 오프라인 3D 비교. **앱 업데이트·실시간 물성 완성은 아니다.**

## 목표와 비교 방법

사용자 원본 `References/liquid-wave/reference-01.jpg`, `reference-04.jpg`, `reference-05.jpg`를 기준으로, 맑은 파란 본체와 둥근 수면이 한 재질로 읽히는 장면을 먼저 만든다. 썸네일의 인상이나 mesh 검사 통과를 미감의 성공으로 대체하지 않는다. 이번 평가는 구현한 root의 **자체 검토**이며 독립 미감 심사나 사용자 승인이 아니다.

이전 GPU 필드에 광학 계수를 계속 추가하는 대신, 하나로 닫힌 파도 mesh와 투명 용기, 주변 조명을 함께 만든다. `ToyMaterialCalibration.py`의 파도는 수식으로 지정한 정적 형상이다. 실제 시뮬레이션이라고 표시하지 않는다. 물/맑은 매질/아크릴의 굴절률과 흡수량은 처방 값이며 실물 측정값이 아니다.

## 실제 시뮬레이션 형상과의 연결

`ToyMaterialFromSimulation.py`는 기존에 저장한 실제 앱의 흔들기 직후 상태와 검증한 PLY를 기준 장면으로 가져온다. 입자 상태를 다시 만들거나 액체를 예쁘게 재배치하지 않는다. X/-Z/Y의 강체 회전만 적용하며 크기와 체적은 유지한다. 용기를 폰 비율로 바꾸고 기록된 범선 위치/각도를 사용한다.

`frozen-front-900-96` 렌더 완료: 900×1908 / 96 samples / 137.56초. 원래 mesh 647,662 vertex / 1,295,308 face, 체적 1.06771849 및 non-manifold edge 0 확인. 소스/입력은 실행 시작 시 고정했다.

정상 크기의 자체 검토에서 본체와 솟은 부분이 연결되고, 투명한 방울·둥근 수면·맥락이 있는 반사가 전보다 분명해졌다. 그러나 내부의 짙은 반점과 큰 평면, 너무 밝은 경계는 남아 있다. 이는 **재질 기준으로 쓸 수 있는 부분 진전**이며 원본 장난감의 외관에 도달했다는 판정은 아니다. 물리 시뮬레이션의 한 순간을 사용했지만 결과는 정적인 오프라인 렌더다.

## 빠른 Metal 후보

실시간 구현을 향한 별도 후보 `FastMaterial.metal`, `PrepareFastMaterial.py`, `Tests/FastMaterialRender.swift`를 만들었다. root는 준비/재질, Terra는 입출력·검증 harness를 담당했다. 앱 기본 파일에 넣지 않았다.

준비 코드는 같은 cubic 필드의 격자 중심 값을 `[1,4,1]/6` 세 축 필터로 계산하고, 같은 기포 공간을 뺀다. 준비한 실제 상태는 000/012/024/036/047이며 유한 좌표 검사를 통과했다. 각각 약 0.14~0.19초 걸린 CPU 준비 시간이며 실시간 구현은 아니다.

Metal 후보는 3D 텍스처의 필드를 따라 맑은 매질/청색 액체의 경계를 추적한다. 전반사는 내부에서 계속 추적하지만, 전반사가 아닌 작은 반사 성분은 환경을 직접 조회하는 근사가 있다. 바깥 아크릴은 별도 두께 대신 유효 경계로 근사한다. Cycles와 같거나 물리적으로 완전한 광선 추적이라고 주장하지 않는다.

|---|---:|---:|---|
| 하드웨어 보간 + 중앙 차분 법선 | .05834초 | 3,970 | FAIL |

법선·보간 정합만으로 오류가 해결되지 않았다. 한도를 늘리거나 오류를 배경색으로 가리지 않는다. 광학 오류와 함께 넓은 파란 평면·연한 곡면의 분리, 전면 조명 카드의 흰 사각형이 다시 나타나 **앱 미채택**이다. 이 숫자는 입력 준비·시뮬레이션을 제외한 Mac의 해당 정지 장면 GPU 시간이며 아이폰 FPS가 아니다.

첫 harness는 오류가 있어도 `PASS frame=0 errors=3970`를 출력하는 결함이 있었다. root가 발견했고 Terra가 고쳤다. 이후 PNG/manifest를 남긴 뒤 오류가 하나라도 있으면 실패 종료한다. 최초 PASS 문구를 성공 근거로 사용하지 않는다. command status 검사, 유효하지 않은 GPU 시간의 null 처리, 시작 시점 harness/실행파일 해시도 추가했다.

### 한 픽셀의 실제 GPU 경로

`FastMaterialTrace.swift` / `FAST_PROBE`로 오류 픽셀 (586,874)만 직접 기록했다. 해당 픽셀은 **31번째 bounce, 2,049번째 표본에서 global step 한도에 도달**했다. 남은 throughput 최대는 약 1.97e-5였다. 이 픽셀에서 0거리 경계 반복이 원인이라고 한 가설은 지지되지 않았다. `.build-cache/fast-material/probe-gpu/rawtrace.json` 및 실행 소스/입력 해시 보존.

Terra의 첫 CPU 대조는 `refract` 부호가 틀려 정면 입사의 방향 길이부터 달랐다. root 검토로 발견하고 수정했으며 기존 `one-ray.json`은 무효 증거로 남겼다. `one-ray-v2.json`은 정면/사선 단위 방향 sanity PASS, 같은 픽셀에서 global 2,048-step 초과를 재현했다. CPU는 청색 흡수를 생략하므로 throughput·종료 시점까지 GPU와 같다고 주장하지 않는다. 실제 원인 판정은 GPU 기록에 둔다.

이 새 근거 때문에 약한 주 경로 꼬리의 종료 기준을 바꿨다. 기존 고정 throughput 1e-6 대신, 남은 에너지×모든 광원/오브제 radiance의 상한 5를 실제 단조 표시 변환에 통과시켜 출력 차이 상한을 계산한다. 그 상한이 채널별 **8비트 한 단계의 1/4 이하**일 때만 종료한다. 광선 횟수/step 한도는 그대로다. 이는 후보 내부 모델의 남은 주 경로 오차 상한이며, 별도 반사 근사의 정확성 보증이 아니다. 원래 결과를 소급해 PASS로 바꾸지 않는다.

이 후보도 오류 2,280개 / M1 .10738초로 **FAIL**, 외관 역시 미채택이다. 더 이상 이 근사 방식의 색/한도를 반복 조정하지 않는다.

## 다음 방법 대조

`StochasticMaterial.metal`은 일부 반사를 환경으로 바로 보내던 근사를 버리고 반사/굴절 경로를 확률적으로 선택해 실제 필드 안에서 추적한다. Russian roulette를 쓰며 살아남은 경로의 weight를 확률의 역수로 보정한다. 창의 위치도 정면 시야 밖에 두는 별도 공간 조명을 사용한다. 생성된 실제 결과를 보기 전에는 재질 성공·앱 채택·아이폰 성능을 판정하지 않는다.

실제 캐시 6개(`path-spp32-seed719-600`, `range-control-600`, `range-skip-600`, AOV 3장)의 `frame.png`와 `compiled-source.metal` SHA-256은 각각 `render.json` 기록과 일치했다. field/state/app shader 해시도 일치했다. 다만 현재 `FastMaterial.metal` 해시는 6개 모두 기록과 다르고, 현재 `StochasticMaterial.metal`은 앞의 path/range 3개와 다르며 AOV 3개와만 일치한다. 따라서 과거 결과 해석에는 각 폴더의 source snapshot을 사용해야 한다.

32 spp, 600×1272의 full path는 magenta 1개와 GPU 2.0090초를 기록했다. 넓은 흰 패널은 줄었지만 큰 짙은 반점과 입자 노이즈가 남아 원본 실물 목표에는 미달하며 앱에 채택하지 않는다. range control(`--no-skip`)은 오류 1개·1.8810초, homogeneous block skip은 오류 0개·0.9760초였다. 약 1.93배는 이 정지 장면의 이 두 측정값 비율일 뿐 아이폰 성능 수치가 아니다.

normal/depth/thickness AOV는 광학을 제거해 원인을 분리하는 진단 이미지이며 미감 성공 증거가 아니다. 세 AOV는 각 오류 0개였지만, 이 사실은 본 렌더의 재질·외관 성공을 뜻하지 않는다.

## 연속 표면 보간의 독립 대조

Astra의 읽기 전용 검토는 normal AOV의 셀 단위 띠를 확인하고, 표면과 법선을 함께 매끄럽게 만드는 대조를 권고했다. `FAST_CUBIC_FIELD`는 준비한 동일 격자에 64개 값을 사용하는 cubic B-spline을 적용하고 그 함수를 해석적으로 미분한다. 기존 field를 다시 재구성하므로 표면이 약간 바뀌며, 기존 block bounds는 맞지 않아 skipping을 껐다. 입자·조명·막 두께는 유지했다.

`ContinuousFieldCheck.py`: 96점 미분 대조 최대 오차 4.21e-11, 격자 경계 72회 gradient 차이 최대 6.82e-8 PASS. 중심 표본으로 추정한 점유 체적은 1.07664044→1.07631345(−.03037%). 정확한 mesh 체적이나 물리 질량 보존 검사가 아니다. 왼쪽 ROI(0,490,185,250)의 첫 표면 깊이 AOV 평균 차이 .000363, 99백분위 .002824, 최대 .115765, 가시성 변경 47픽셀이다. 최대값에는 가림 경계에서 첫 교차면이 바뀌는 경우가 포함되므로 모든 위치의 형태 차이가 작다고 주장하지 않는다.

정밀 광선 32개를 한 pass에서 계산한 시도는 전체 화면과 4행 ROI 모두 GPU Hang으로 FAIL. AOV와 같은 ROI의 한 광선 경로는 PASS여서, 경로를 하나씩 계산해 선형 RGB로 합친 뒤 마지막에 표시 변환하는 progressive harness를 만들었다. 오류는 alpha 채널에 누적해 하나라도 있으면 magenta로 남긴다. 초기 버전은 기본 clear alpha=1 때문에 전체 763,200픽셀이 오류 표시됐으며, root가 명시적인 0 초기화로 고쳤다. v2의 한 광선 직접/누적 대조는 채널 차이 최대 1/255, 초과 픽셀 0. 별도 실제 GPU 4입력 검사에서 정상 radiance·한 경로 실패·overflow·빈 입력 처리 PASS.

같은 32개 seed의 progressive 대조는 두 방식 모두 오류 0이다. ROI GPU 시간은 기존 linear .57297초, cubic 12.58641초. 구현자와 독립 Astra 모두 **미세 띠는 줄지만 큰 짙은 얼룩과 밝은 가장자리의 분리는 남는다**고 판단했다. 미세 띠와 큰 얼룩의 동시 해결 기준 FAIL, 앱 미채택. 보간 불연속이 큰 얼룩의 주원인이라는 가설은 약해졌다. 정밀 보간을 더 최적화하거나 앱에 넣는 작업으로 확대하지 않는다.

근거: `.build-cache/fast-material/000/`의 `cubic-*-roi-600`, `linear-progressive-32-roi-600`, `progressive-one-control-v2-roi-600` 및 실패 폴더. root는 AOV/직접/실패/수정/누적 비교 10개 PNG와 compiled source의 기록 해시를 모두 대조했다. 과거와 현재 소스가 다른 것은 후속 편집 때문이며, 각 결과는 폴더에 고정한 실제 실행 소스로 해석한다. 앱 파일과 기기 빌드에는 적용하지 않았다.

## 큰 얼룩의 원인과 현재 기준 이미지

C2 대조 뒤, 광원 카드의 위치·크기를 유지하고 20% 폭의 smoothstep 경계로 바꿨다. 각 축 적분 .8, 방출 radiance를 1/.64로 보정해 카드의 총 방출 성분을 유지했다(중간점 10,000개 수치 대조 PASS). 부드러운 가장자리는 뒤의 환경을 일부 통과시키며, 이는 방출 성분 보존과 구별한다. 꺼짐 대조는 이전 linear progressive PNG와 바이트 동일. cubic ROI 비교는 오류 0 / 14.04초지만 **큰 얼룩은 유지**, 미채택이다.

다음 `source` AOV는 실제 광선의 도착 대상을 world=빨강, floor=초록, card=파랑, toy=노랑으로 표시한다. 흡수와 roulette 선택은 실제 경로대로 진행하되, 반환된 표시는 에너지 가중치 없이 도착 대상만 나타낸다. 에너지 기여율이 아니다. skip을 끈 첫 진단에는 기존 광선 오류 1개가 남았고, 검증한 skip을 켠 진단은 오류 0이었다. **초록 바닥 영역이 큰 밝은 얼룩과 대응했다.**

원래 가상 바닥은 무한히 먼 곳까지 주변 공간보다 밝았다. 표면 굴절이 그 불연속을 커다란 얼룩으로 비추고 있었다. `--soft-floor`는 원거리 바닥 조명을 `exp(-dot(q.xz,q.xz)/18)`로 주변광에 수렴시킨다. 액체의 입자·격자·법선·굴절률·흡수량·광선 선택은 유지했다. 실제 원본의 조명을 측정/복제했다는 의미는 아니다. 원거리 조명 모델을 바꾼 대조다.
