# 정지 수면의 입자 요철 — 2026-09-12

요구사항은 움직임이 잦아들면 수면이 거의 평평해지고, 다시 흔들면 액체의 둥근 덩어리·분리·합체가 유지되는 것이다. 정지 수면 문제를 흔들림의 힘 계수나 범선 부력 변경으로 해결하지 않는다.

2026-09-13 build 13 사용자 평가: 수면 요철이 여전히 심하므로 재오픈했다. 아래 GPU 비교 통과는 제한된 조건의 개선 근거이며 사용자 요구를 충족했다는 뜻이 아니다. 현재 폰에도 들어간 필터와, 아직 통합하지 않은 새 후보를 구분한다.

## 관찰과 버린 후보

120Hz로 12초 정지시킨 1,200입자 상태에서도 GPU 수면 중앙 단면의 높이 RMS는 .004082, 최고/최저 차이는 .017766 scene unit이었다. 원래 입자 반경을 접선 방향으로 3배 늘린 첫 후보는 최고/최저 차이를 .007837로 줄였지만, 벽 반사용 draw instance가 9배가 되고 작은 고립 방울을 지울 가능성이 있어 채택하지 않았다. 입자 수가 같다는 사실만으로 가시 부피·방울 보존을 주장하지 않는다.

## 현재 후보의 동작

- 기존 입자 splat와 힘 계산을 유지한다. 이미 구성한 밀도 필드에만 접선 방향의 9탭 필터를 적용한다. 수면 법선과 앞뒤 깊이를 직접 흐리지 않는다.
- 중력 방향과 손이 안정되고 전역 에너지가 낮아야 한다. 추가로 모든 입자가 이웃 거리 기준으로 연결돼 있고 각각의 속도가 .25 이하인지 검사한다. 이 검사에서 분리되거나 빠른 입자가 잡히면 즉시 기본 필드로 복귀한다. 입자의 연결성이 모든 시각적 액체 경계의 연결을 보장하는 것은 아니다.
- 실제 경과시간으로 .75초 대기 후 1.4초 시정수로 서서히 진입한다. 250ms를 넘는 간격은 정지 판정을 초기화한다. 멈춘 화면의 수동 재그리기에서는 상태를 진행하지 않는다.
- 벽 바깥 샘플을 반사해 처리한다. 이것이 정확한 물/기름 CFD나 모든 상태에서의 부피 보존을 의미하지는 않는다.

## 검증 범위와 기준

`Tests/LiquidSurfaceRestCheck.swift`는 상태 전환, 연결성, 소수 빠른 입자, 시간 간격과 잘못된 입력을 검사한다. `Studies/RestSurfaceGPUCheck.swift`는 같은 동결 입자를 기존/기본/정지 경로로 그려 비교한다. 출력은 앱과 같은 480px 짧은 변의 광학 렌더를 확대하며 UI 오버레이는 포함하지 않는다.

GPU 비교 기준: 기본 경로의 밀도 오차 ≤.002, iso 판정 차이 ≤334/6,684,672 voxel, 중앙 평균 수위 차이 <.0002. 정지 후보는 점유 voxel 변화 <.5%, 중앙 평균 수위 변화 <.004, 직선 대비 잔차 RMS 비율 <.8, 벽까지 포함한 5개 깊이 단면의 평균 수위 변화 <.008 및 교차 개수 변화 ≤4를 요구한다. 모든 필드는 유한해야 하고 공간 건너뛰기 경계는 실제 밀도를 포함해야 한다.

이 허용 오차는 물리적인 질량 보존의 증명이 아니다. 실제 폰 처리 속도와 흔들림→정지 전환의 시각·촉각 평가는 별도 확인 대상이다. 수치와 렌더 결과는 실행별 `.build-cache/rest-surface-20260912/`에 보관한다.

## 실제 시뮬레이션에서의 활성 확인

2026-09-13에는 현재 solver를 30Hz 화면 간격으로 12초 진행하면서 렌더러와 같은 연결성·속도·에너지 조건을 적용했다. 직립에서 필터 세기는 6초 .864665, 12초 .998137이었다. 30도에서는 2초의 비연결 상태를 거부했고 6초 .585612, 12초 .994296이었다. 수동으로 필터를 최대로 고정한 GPU 비교 외에 실제 상태 전환이 정지 조건에서 활성화됨을 확인한 것이다. 이 CPU 확인은 iPhone에서의 단독 비용 측정은 아니다.

## 사용자 평가 후 확인할 두 경로

현재 렌더러는 가속도 .06g 이상 또는 에너지 .13 이상도 비연결 상태와 같은 `coherentBulk=false`로 전달한다. 이때 필터 세기는 즉시 0으로 초기화된다. 입자 하나의 분리·빠른 속도도 전체 필터를 끈다. 중력 방향 변화율 .10/s 이상은 대기시간을 초기화하며, 재진입에는 .75초 연속 안정이 필요하다. 실제 손에서 얼마나 자주 비활성화되는지는 폰의 기록으로 확인해야 한다.

9탭 이항 필터의 최대 접선 간격은 약 .0886 scene unit이다. 이상적인 응답 `cos⁸(kΔ/2)`에 입자 간격 .098을 대입하면 해당 성분의 약 69%가 통과한다. 큰 간격의 성긴 샘플링이 입자 크기 요철을 다시 통과시킬 수 있다는 코드상 근거다. 이것이 실제 폰 요철의 주된 주파수라는 사실은 아직 확인하지 않았다.

## 좁은 간격 후보 기각 — 2026-09-13

접선 간격만 .0245 이하로 제한하고 입자·힘·활성 조건·광학을 유지해 비교했다. 1206×2557 렌더의 단면에서 최적 직선을 뺀 잔차를 측정했다. 절대 기준은 RMS ≤.5px, 최고/최저 차이 ≤2px이다. 기울어진 수면의 전체 높이 차이를 요철로 세지 않는다.

| 동결 상태 | 현재 필터 RMS / 최고·최저 차이 | 좁은 간격 후보 RMS / 최고·최저 차이 |
| --- | --- | --- |
| 직립 | 1.442 / 4.843px | 2.201 / 8.421px |
| 30도 기울임 | 1.130 / 4.647px | 1.810 / 7.431px |

후보는 오히려 굴곡이 커져 기각했다. 유한 값·수위·점유·공간 경계 검사를 통과해도 미감 기준은 통과하지 못했다. 앱에는 반영하지 않는다. 샘플 간격을 줄이며 전체 필터 폭도 줄인 것이 넓은 굴곡 억제에 불리했다.

현재 필터의 중앙 단면 잔차를 Hann 창 DFT로 분해하면, 파장 .25 scene unit 이상 성분이 직립 99.24%, 기울임 91.72%였다. 입자 간격 부근(.08–.12)의 비중은 각각 .70%, 8.24%였다. 제한된 동결 단면의 기술 통계이며 실제 폰의 원인을 확정하지 않지만, 이 자료에서는 넓은 굴곡이 우세하다. 탭 개수만 늘리는 추가 후보는 실행하지 않았다.

## 정지 형상의 시간 기록

build 13 동결 솔버를 직립·무가속 조건으로 진행하고 12–14초 사이 21상태를 기록했다. 5개 깊이에서 입자 상단 분포와 CPU raw poly6 iso를 비교했다. 1,200입자를 유지하고 모든 기록은 유한했다. 솔버·힘·경계·표시 코드는 바꾸지 않았다.

raw iso 잔차 중 같은 위치에 남는 시간 평균 형상의 비중은 93.9–98.5%였다. 중앙 단면의 시간 평균 형상 RMS는 .003955, 시간 변동 RMS는 .000640 scene unit이었다. 넓은 입자 상단 굴곡과 raw iso 굴곡의 상관도 중앙 .968이었다. 이 2초 구간에서는 입자 상단 배치와 동반된 고정 굴곡이 지배적이었으며, 큰 잔류 파동만으로 설명하기 어렵다.

입자 배치의 원인과 밀도 재구성·깊이벽의 기여는 아직 분리되지 않았다. CPU raw iso에는 GPU 필터·벽 coating·최종 굴절이 없고, 더 느린 파동이나 실제 손의 움직임을 배제하지 않는다. 다음 진단은 같은 봉우리·골의 밀도 제약 잔차와 깊이벽의 보정 방향 비교다. 평면으로 덮어 요철이나 물기둥을 숨기는 변경은 하지 않는다.

비교 원자료는 로컬 `.build-cache/rest-surface-fine-taps-20260913/`, 시간 기록은 `.build-cache/rest-temporal-20260913/`에 보관한다. build 14의 입력 증폭과 이 미해결 수면 조사는 별개다.

## 밀도와 보정 방향의 후속 확인

사용자 기준을 다시 확인했다: 흔들 때 생기는 둥근 방울과 기포는 살리고, 충분히 안정된 수면은 매끈해야 한다. 정지 수면을 개선하기 위해 동적인 방울 표현을 희생하는 후보는 채택하지 않는다.

직립 20초를 한 번 진행하며 12·14·20초의 한 물리 step을 계측했다. 상단 입자의 응집에 따른 하향 이동은 기존 속도·중력 예측 이동의 약 72–75%였고, 세 번의 밀도 보정이 두 이동을 위쪽으로 상쇄했다. 20초의 중앙 봉우리·골은 서로 다른 높이에서 밀도 1.000384/.999762로 목표 1에 가까웠다. 따라서 큰 밀도 제약 잔차가 남아 요철이 생긴다는 설명만으로는 부족하다.

깊이벽 지원은 앞뒤의 낮은 상단과 동반됐지만, 벽 지원이 거의 없는 중앙에도 굴곡이 남았다. 응집과 압력의 입자 배치 평형이 다음 비교 대상이며, 벽이나 응집을 제거하면 해결된다는 증거는 아니다. 동결 코드의 기존 응집 강도 18→9 비교는 다음 후보로만 기록했다. 아직 실행하거나 앱에 반영하지 않았다. 수면 절대 기준·수위·밀도와 방울/기포·분리/합체 보존을 함께 판정해야 한다.

이 관측에서는 1,200입자·2,400step과 유한 값을 확인했다. 관측 코드를 제거하면 동결 솔버 원본 바이트가 복원됐지만, 계측 전후 실행 궤적의 완전한 일치까지 추가 비교하지는 않았다. 상단 proxy는 최종 GPU 수면이 아니며, 실제 폰의 미감 판정은 여전히 남아 있다. 근거는 로컬 `.build-cache/rest-density-20260913/`에 보관한다.
