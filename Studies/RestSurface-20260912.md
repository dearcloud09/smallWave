# 정지 수면의 입자 요철 — 2026-09-12

요구사항은 움직임이 잦아들면 수면이 거의 평평해지고, 다시 흔들면 액체의 둥근 덩어리·분리·합체가 유지되는 것이다. 정지 수면 문제를 흔들림의 힘 계수나 범선 부력 변경으로 해결하지 않는다.

## 관찰과 버린 후보

120Hz로 12초 정지시킨 1,200입자 상태에서도 GPU 수면 중앙 단면의 높이 RMS는 .004082, 최고/최저 차이는 .017766 scene unit이었다. 원래 입자 반경을 접선 방향으로 3배 늘린 첫 후보는 최고/최저 차이를 .007837로 줄였지만, 벽 반사용 draw instance가 9배가 되고 작은 고립 방울을 지울 가능성이 있어 채택하지 않았다. 입자 수가 같다는 사실만으로 가시 부피·방울 보존을 주장하지 않는다.

## 현재 후보의 동작

- 기존 입자 splat와 힘 계산을 유지한다. 이미 구성한 밀도 필드에만 접선 방향의 9탭 필터를 적용한다. 수면 법선과 앞뒤 깊이를 직접 흐리지 않는다.
- 중력 방향과 손이 안정되고 전역 에너지가 낮아야 한다. 추가로 모든 입자가 이웃 거리 기준으로 연결돼 있고 각각의 속도가 .25 이하인지 검사한다. 이 검사에서 분리되거나 빠른 입자가 잡히면 즉시 기본 필드로 복귀한다. 입자의 연결성이 모든 시각적 액체 경계의 연결을 보장하는 것은 아니다.
- 실제 경과시간으로 .75초 대기 후 1.4초 시정수로 서서히 진입한다. 250ms를 넘는 간격은 정지 판정을 초기화한다. 멈춘 화면의 수동 재그리기에서는 상태를 진행하지 않는다.
- 벽 바깥 샘플을 반사해 처리한다. 이것이 정확한 물/기름 CFD나 모든 상태에서의 부피 보존을 의미하지는 않는다.

## 검증 범위와 기준

`Tests/LiquidSurfaceRestCheck.swift`는 상태 전환, 연결성, 소수 빠른 입자, 시간 간격과 잘못된 입력을 검사한다. `Studies/RestSurfaceGPUCheck.swift`는 같은 동결 입자를 기존/기본/정지 경로로 그려 비교한다. 출력은 앱과 같은 480px 짧은 변의 광학 렌더를 확대하며 UI 오버레이는 포함하지 않는다.

GPU 비교 기준: 기본 경로의 밀도 오차 ≤.002, iso 판정 차이 ≤334/6,684,672 voxel, 중앙 평균 수위 차이 <.0002. 정지 후보는 점유 voxel 변화 <.5%, 중앙 평균 수위 변화 <.004, 직선 대비 잔차 RMS 비율 <.8, 벽까지 포함한 5개 깊이 단면의 평균 수위 변화 <.008 및 교차 개수 변화 ≤4를 요구한다. 모든 필드는 유한해야 하고 공간 건너뛰기 경계는 실제 밀도를 포함해야 한다.

이 허용 오차는 물리적인 질량 보존의 증명이 아니다. 실제 폰 처리 속도와 흔들림→정지 전환의 시각·촉각 평가는 별도 확인 대상이다. 수치와 렌더 결과는 실행별 `.build-cache/rest-surface-20260912/`에 보관한다.

## 실제 시뮬레이션에서의 활성 확인

2026-09-13에는 현재 solver를 30Hz 화면 간격으로 12초 진행하면서 렌더러와 같은 연결성·속도·에너지 조건을 적용했다. 직립에서 필터 세기는 6초 .864665, 12초 .998137이었다. 30도에서는 2초의 비연결 상태를 거부했고 6초 .585612, 12초 .994296이었다. 수동으로 필터를 최대로 고정한 GPU 비교 외에 실제 상태 전환이 정지 조건에서 활성화됨을 확인한 것이다. 이 CPU 확인은 iPhone에서의 단독 비용 측정은 아니다.
