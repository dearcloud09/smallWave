# smallWave 완성도 작업 목록

2026-09-12 사용자 요청: 진행 중인 물리 문제를 해결하면서 기존 미감 리뷰의 항목도 하나씩 이어서 수정한다. 현재 귀여운 범선과 자연스러운 느린 기울임은 보존 기준이다. 아래 상태는 완료 주장과 구분한다.

| 항목 | 상태 | 완료 판단 |
| --- | --- | --- |
| 좌우 벽의 긴 액체 기둥 | build 13에서도 사용자가 잔존 재확인. 압력/반발 후보 미채택, 앞뒤 중력 조건도 정확한 형태 미재현. 기록 도구 설치 완료, 연결 후 새 식별자로 실폰 재현 기록 필요 | 좌우 기울임·급반전 후 얇은 기둥이 고착되지 않고 본체로 돌아옴. 가시 액체를 단순히 잘라 감추지 않음 |
| 빠른 반복 흔들림 | 사용자는 입력 약화 해제 후 개선됐지만 최소 3배 더 격렬한 반응을 요청. build 14에 강한 선형 가속도 3배 매핑 준비; 합성 1·2·3Hz 비교 완료. 실제 폰은 아직 build 13, 새 체감 확인 전 | 1·2·3Hz와 정지 전환에서 방향 전환이 반영되고, 빠르게 흔들어도 연속 움직임이 누락되는 느낌이 없음. 계산상 입력 배수와 실제 화면의 이동 폭·손맛을 구분 |
| 정지 수면 요철 | **재오픈: build 13 사용자 평가에서 요철이 여전히 심함.** 좁은 간격 필터는 더 나빠져 기각. 직립 12–14초 기록에서 입자 상단 분포와 동반된 고정 굴곡 확인; 발생 원인과 실제 손에서 필터 활성 여부는 미확인 | 물방울·분리가 남아 있는 동안 보존, 충분히 정착하면 거의 직선. 상대 개선율에 더해 최종 표시 크기의 절대 요철·벽·수위·부피 및 실폰 사용자 평가로 판정 |
| 본체–수면–목–방울 재질 연결 | 다음 광학 비교 | 진한 파랑과 시안 경계가 별개 재질처럼 보이지 않고 하나의 액체 두께 변화로 읽힘 |
| 배와 물의 접촉 | 5자세·180프레임×3색 검증 후 665277e에 저장·실폰 설치. 실물 마감 평가는 계속 | 회색 받침처럼 보이는 잠긴 선체 제거, 정지/기울임/반잠김/재부상에서 같은 수면에 접촉 |
| 작은 곡면의 점선·깜박임 | 임계각 경로의 픽셀 표본 부족 근거 확인. 선택적 추가 광선은 스틸 개선·독립 검토 통과, 시간축·폰 성능 미확인으로 앱 통합 보류 | 정상 폰 크기와 확대 화면 모두에서 윤곽이 끊기지 않고 물방울을 지워 해결하지 않음 |
| 위젯의 같은 소유물 | 물리·재질 후 통합 | 앱에서 고른 배와 바다를 위젯에서도 알아볼 수 있고 선택 유지 |
| 소리·진동의 타이밍 | 움직임 안정 후 조정 | 물 충돌·합체와 타이밍이 맞고 바람/모래처럼 들리는 소리 개선 |

한 번에 한 원인군을 바꾸고 같은 상태·동작의 전후 비교를 남긴다. 합성 입력의 검사 통과, Mac 렌더, iPhone 빌드·설치, 실제 손맛 승인은 각각 별도 근거다. 날씨·배경·오브제 종류 확대는 이 마감 작업 후의 제품 과제로 남긴다.
