# 좌우 벽의 좁은 액체 기둥

상태: 미해결. 사용자가 build 10에서도 확인했다. build 11은 흔들림 반응을 선택하는 기능을 추가했으며 벽 기둥을 고친 버전이 아니다. build 12는 실제 폰 장면을 재생하기 위한 개발용 기록 기능을 추가한다.

## 현재까지 배제한 결론

기울임·수평 가속 후 복귀하는 합성 입력에서 벽 쪽 액체가 높이 올라갔다가 내려오는 현상은 확인했다. 그러나 사용자 사진의 좁고 길게 남는 형태와 정확히 일치하지 않았다. 이전 build 9의 3g 상한과 0.2배 입력 조건도 별도로 재현했다. 벽 충돌 때 낙하 속도가 사라진다는 가설은 해당 기록으로 지지되지 않았다.

벽 압력 보완 후보와 반발 계수 후보는 좌우 모두를 개선하지 못해 채택하지 않았다. 입자 수가 같거나 수치가 유한하다는 것만으로 모양과 물성을 통과시킨 것이 아니다.

앞뒤 중력까지 포함한 추가 조건은 직립 1.5초, `(±√0.5, 0, −√0.5)`로 2초, `(0, −√0.5, −√0.5)`로 복귀한 뒤 0·0.5·2·5초다. 수직 구조가 실제 GPU 렌더에 나타났으나 사용자 사진보다 넓은 막 형태였다. 깊이 전체의 중앙 입자 높이를 기준으로 한 간단한 기둥 검출은 얇은 뒷면 막을 본체 수면으로 오인할 수 있으므로 시각적 음성 판정에 사용하지 않는다.

## build 12의 기록 범위

Xcode의 앱 실행 인수에 `--smallwave-wall-capture=<새 식별자>`를 줄 때만 동작한다. 식별자는 영문·숫자·밑줄·하이픈으로 1~64자다. 일반 아이콘 실행에서는 기록을 만들지 않는다.

활성 렌더의 약 0·2.5·5·7.5·10·12.5·15·17.5·20초 상태를 최대 9개 저장한다. 입자 위치·속도, 기포, 범선, 중력·가속도, 정지 필터, 최종 화면 크기와 셰이더 입력이 포함된다. 일시 정지나 프레임 간격으로 놓친 시점은 이전 상태로 채우지 않으며 실제 경과시간을 남긴다. 정지한 경우에도 마감 시각에 이미 복사한 부분만 저장한다.

결과는 앱의 로컬 캐시 `Library/Caches/smallwave-wall-capture.json` 한 파일이다. 네트워크 전송은 없고 위치·계정·기기 식별자는 기록하지 않는다. 파일에는 입자 상태가 있으므로 Git에 넣지 않는다. 개발자가 연결한 폰에서 이 파일만 가져온다.

## 재생과 판단

```sh
python3 scripts/extract-wall-capture.py capture.json replay-output \
  --expected-build 12 --expected-capture wall_example
sh scripts/study-material-edge.sh replay-output/000.json render-output --diagnostics
```

출력 폴더는 새 경로를 사용한다. 가져온 파일의 build·식별자를 기대값과 대조하고 원본 바이트의 SHA-256 및 각 프레임의 SHA-256을 남긴다. 다른 실행의 오래된 캐시를 이번 증거로 사용하지 않는다.

재생은 같은 입자 상태의 시각 비교다. 연속 센서 로그나 시뮬레이터 내부의 전체 상태를 저장한 것은 아니므로 이후 물리 경로까지 완전히 재현했다는 뜻은 아니다. 현 앱의 기포 표시·범선 텍스처·광학 코드를 그대로 사용하며 UI 오버레이는 포함하지 않는다. GPU의 미세한 수치 차이도 있을 수 있다.

기록은 GPU 완료 전에 렌더 입력을 복사한다. 따라서 해당 프레임이 실제 화면에 표시됐다는 증명은 별도로 필요하다. 파일 해시는 복사한 바이트의 일치를 확인하며 기기나 설치 소스를 인증하는 서명은 아니다.

기둥이 잡힌 프레임에서는 입자 분포, 재구성한 액체 경계, 최종 굴절 영상을 비교한다. 입자 문제와 그리기 문제를 구분한 뒤 같은 상태에서 좌우 복귀·수위·정지·느린 움직임을 검증한다. 화면 끝의 액체를 단순히 잘라 숨기는 수정은 완료로 보지 않는다.

## 확인한 범위

- 기록 기능의 5개 검사: 실행 인수, 시점·유한 값·렌더 입력, 놓친 시점 제외, 잘못된 상태 제외, 정지 후 마감 저장.
- 추출 도구: 원본 해시, 정상 재생, 이전 build/다른 식별자 거부, 빈 입자·과도한 수치·화면 크기 거부.
- 같은 build 12 소스로 iPhone 앱과 위젯의 서명 없는 빌드 성공. 설치용 서명과 실제 폰 기둥 기록은 별도 단계다.
