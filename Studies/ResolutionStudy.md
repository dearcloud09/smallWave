16:03 BST 사용자 교정 반영: 액체는 이어졌다가 나뉘고 다시 합쳐지는 것이 목표다. 전담 시각 비평가는 목·가지·분리 방울 자체를 기각 근거로 삼은 부분을 철회했다. 원형 윤곽의 부당한 지속과 병합의 자연스러움은 현재 PNG 표본으로 미검증이다. 뿌연 경계·내부 얼룩이라는 광학 관측과 수위·운동 차이로 인한 대조 한계는 유지한다. 아래 최초 판정은 실험 이력이며 이 교정이 우선한다.

## 대조 방법

`Studies/prepare_resolution_study.py`가 현재 앱 소스를 읽어 `.build-cache/resolution/`에 coarse/fine 연구 복사본을 만든다. 정확히 일치하는 부분만 치환하며 예상 기준 코드가 바뀌면 중단한다. 앱 소스를 덮어쓰지 않는다.

| 항목 | 기존 coarse | fine 후보 |
|---|---:|---:|
| 입자 수 | 1,200 | 9,600 |
| 입자 간격 | 0.098 | 0.049 |
| 이웃 반경 | 0.177 | 0.0885 |
| 물리 step | 1/120초 | 1/240초 |
| 정규화 총 질량 | 1.1294303114 | 1.1294303114 |
| 초기 중심 y | -1.1301652 | -1.1301663 |
| 안정화 후 첫 표본 중심 y | -1.5238001 | -1.3439131 |

기존 seed 하나를 대칭인 8개 자식으로 나눠 총 질량과 중심을 유지한다. 같은 크기의 용기와 장난감, 같은 3.5초 안정화와 10초 입력(기울임·흔들림·정지·옆으로 돌리기·뒤집기·복귀)을 쓴다. 힘과 벽의 위치는 월드 단위로 유지한다. λ 안정화 항은 4배, antiClump 계수는 1/4, 시간 감쇠는 제곱근, XSPH는 2배로 바꿨다. 투영 kernel 면적·입자 수 변화에 따라 렌더 밀도 진폭을 1/2로 조정했다.

이 정규화가 동일한 운동을 보장하지 않는다. 응집력·구속 3회·부력 probe 지지 범위·기포 생성이 해상도에 따라 달라진다. XSPH 조정도 연속 확산 계수의 근사이며 실제 점도 측정이 아니다. 수위와 물 배치의 차이가 실제로 관측됐으므로 순수 렌더 지름 비교나 해상도 수렴 검사로 해석하지 않는다.

## 결과와 독립 시각 판정

전담 Astra 비평가는 원본과 두 조건의 000·042·048·054·089·119 PNG를 코드 설명 없이 대조했다.

- fine의 일부 목과 돌출은 가늘어졌지만, 048에서는 작은 혹과 손가락 같은 가지가 늘어났다. 큰 원 덩어리를 작은 울퉁불퉁한 가지로 바꾼 인상이 남는다.
- 아래쪽 본체는 연결돼 있으나 강한 변형에서는 긴 수면보다 가지·혹이 먼저 읽힌다. 뿌연 경계와 내부 얼룩 때문에 맑은 액체라는 원본 목표에 미달한다.
- 시작 수위·변형 단계·배 위치가 달라 보이는 차이를 해상도 하나의 효과로 돌릴 수 없다. 비평은 PNG 표본만으로 이루어졌으며 GIF 연속 재생·실기기 체감은 미검증이다.

추가로 입자 수부터 올리는 반복은 보류한다. 먼저 분리된 부분이 본체에 돌아오는 사건을 따라가며 재접촉 이후 윤곽이 자연스럽게 해소되는지 비교한다. 이 검증 전에는 가지의 존재를 특정 물리 모델의 결함으로 단정하지 않는다.

별도 원인 가설은 현재 단일 자유표면 계산에서 생략한 상부 투명 매질의 비압축 흐름·압력 경계다. 구조 검토는 작은 독립 격자 연구의 가치를 인정했지만 아직 구현·선정하지 않았다. 같은 격자 안에서 상부 압력 처리만 다른 대조를 만들 수 있으면 인과 검사를 시도하고, 다른 차이까지 필요하면 모델 간 탐색 비교로만 보고한다. 초기 phase 양·시간·이류를 맞추고 파란 양의 적분·계면 폭·분리 방울·압력 잔차를 확인해, 수치 확산으로 가지를 지우는 결과를 개선으로 취급하지 않는다. 2D·Boussinesq 근사는 실제 두 액체의 밀도비·점도·깊이 방향 흐름 전체를 재현하지 못한다.

## 검사와 보존

- PASS — `DEVELOPER_DIR=/Library/Developer/CommandLineTools sh scripts/test-resolution.sh`의 coarse/fine 컴파일·Metal 실행. 두 조건 모두 10초 동안 입자 위치 유한/경계 및 개수 유지. 각 150프레임 GIF·지연 합계 10초 확인. 비교 GIF도 150프레임/10초 확인했다. 비교 도구의 첫 단일 파일 컴파일은 `-parse-as-library` 누락으로 실패했고 옵션 추가 후 통과했다.
- PASS — 저장 표본 14개에서 입력 시각과 정규화 총 질량 동일, 입자 수 유지. 앱 세 소스의 SHA-256 불변. 단순 mass 보존을 동일한 실물 체적 검증으로 확대하지 않는다.
- 관측 — 생성·렌더·검사를 포함한 Mac M1 하니스의 전체 시간은 coarse 약 3.75초, fine 약 67.20초였다. 서로 다른 처리량의 오프스크린 전체 실행 기록이며 iPhone FPS·에너지·지속 성능이 아니다.
- 독립 p_reviewer — 스크립트와 생성 diff를 읽고 치명적 비교 오류 없음으로 판정했으며, 응집력·반복률·probe 변화 때문에 resolution-only 인과 주장이 불가함을 지적했다. 검사를 직접 실행하지 않았다.
- NOT_RUN — iPhone 빌드·센서·서명·성능, 실제 장난감과 운동 속도 비교, 연속 재생의 세밀한 떨림 평가. 기본 앱은 변경하지 않아 기존 core·렌더 검사 재실행으로 보고하지 않는다.
